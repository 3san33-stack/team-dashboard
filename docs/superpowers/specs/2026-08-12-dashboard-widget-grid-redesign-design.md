# 대시보드 위젯 그리드 리뉴얼 + 멤버 선택 화면 배경 — 설계 문서

## 배경 / 목적
참고 스크린샷(Talvex HR 대시보드 템플릿)의 "카드가 촘촘히 박힌 그리드" 레이아웃과
체크 가능한 리스트, 세련된 캘린더 느낌을 현재 `team-dashboard`에 이식한다.
톤(화이트/블랙)은 바꾸지 않는다 — 레이아웃 구조와 개별 위젯 스타일만 참고한다.
채용/포모도로 등 우리 데이터와 무관한 위젯(Focus timer, Screenings/Placed 등)은 가져오지 않는다.

동시에 최초 진입 시 이름을 선택하는 `MemberSelect` 화면을 사용자가 제공한 사진
(눈 쌓인 소나무 + 초승달, 야간 사진)을 배경으로 꾸민다.

## 범위
1. `app/page.tsx` 그리드 재구성 + 신규 위젯 2개
2. `TaskCalendar` 날짜 셀을 이모지 배지 방식으로 변경
3. `MemberSelect` 배경 이미지 + 커서 추적 달빛 글로우 + 미세 흔들림

기존 기술 스택(Next.js, Supabase, shadcn/ui, motion/react, recharts)만 사용한다.
새 라이브러리 추가 없음.

## 1. 대시보드 레이아웃

### 히어로 축소
기존 `HeroBackground`(커서 추적 블롭 모션, 그라데이션 배경)를 제거하고,
"Good morning, {member}님" 텍스트 + 우측에 전환/업무추가 버튼만 남긴 얇은 헤더로 교체.
그 아래 통계 pill 줄(전체/진행중/완료/지연, CountUpNumber 유지)을 배치.

### 그리드 구성
```
[헤더: Good morning, {member} + 버튼]
[통계 pill 4개]
┌──────────────┬────────────────┬───────────────┐
│ 멤버 진행률    │ 주간 활동 차트   │ Pending        │
│ (기존 위젯)    │ (신규)          │ Actions (신규)  │
├──────────────┴────────────────┴───────────────┤
│ TaskTable (기존, 카드 스타일 라운드/그림자만 조정)   │
├────────────────────────┬────────────────────────┤
│ ContributionReport      │ TaskCalendar             │
│ (기존)                  │ (이모지 셀)               │
└────────────────────────┴────────────────────────┘
```
lg 브레이크포인트 기준 3열/2열, 그 아래는 1열로 스택 (기존 반응형 패턴 유지).

카드 공통 스타일: 라운드 코너 확대, 옅은 그림자, `whileHover={{ y: -4 }}` 정도의
호버 리프트 애니메이션을 모든 카드에 공통 적용 (기존 버튼에 쓰던 패턴을 카드로 확장).

### 신규 위젯: `WeeklyActivityChart`
- 위치: `components/charts/weekly-activity-chart.tsx`
- 데이터: 별도 API/테이블 불필요. 기존 `tasks` prop에서 파생 —
  최근 7일 각 날짜별로 `status === '완료'`이고 `updated_at`이 해당 날짜인 업무 개수를 집계
- 표현: recharts 막대 차트, 요일 라벨(월~일), 로드 시 막대가 순차적으로(stagger) 아래에서 위로 등장
- 데이터가 없는 날은 0 높이 막대로 표시 (에러 상태 없음)

### 신규 위젯: `UpcomingDeadlines` (Pending Actions)
- 위치: `components/upcoming-deadlines.tsx`
- 데이터: `tasks`에서 `status !== '완료'`이고 `due_date`가 가장 임박한 순으로 정렬, 상위 5개
- 표현: 체크박스 + 업무명 + 담당자 + 마감일. 체크박스는 **로컬 state로만 토글**되는
  시각적 표시(취소선 페이드인 + 스프링 체크 애니메이션)이며, Supabase 상태는 변경하지 않는다.
  실제 완료 처리는 기존 TaskTable/TaskFormDialog에서 하도록 위젯 하단에 작은 안내 문구
  ("완료 처리는 업무 목록에서 해주세요") 추가.
- 빈 목록(마감임박 업무 없음)이면 "마감임박 업무가 없습니다" 안내 표시.

## 2. `TaskCalendar` 셀 재설계
현재: 날짜 셀에 해당 날짜 업무 텍스트/개수를 표시, 클릭 시 다이얼로그.

변경 후:
- 셀 내부에 텍스트 대신 업무 상태별 이모지 배지 최대 2~3개를 셀 한쪽(우측 상단)에 배치
  - 지연(마감 지남, 미완료): 🔴
  - 진행중: 🟡
  - 완료: ✅
  - 한 셀에 업무가 여러 개면 상태별로 종류만 1개씩(중복 제거), 최대 3개까지만 표시하고
    나머지는 다이얼로그에서 전체 확인
- 클릭 시 기존 상세 다이얼로그 로직은 그대로 재사용하되, `motion`의 `layoutId`를 셀과
  다이얼로그 컨테이너에 공유시켜 "셀이 확장되어 다이얼로그가 되는" 트랜지션 추가
- 업무가 없는 날은 배지 없이 빈 셀 (기존과 동일)

## 3. `MemberSelect` 배경

### 이미지
사용자가 제공한 `C:\Users\D-045\Desktop\9fbc9f3d-8e97-43b0-aaa0-6575c14feec9.jpg`
(눈 쌓인 소나무 + 초승달, 야간)를 `public/member-select-bg.jpg`로 복사해 사용.

### 배경 흔들림
전체 이미지 컨테이너에 `motion.div`로 아주 미세한 회전(±1~2deg)과 스케일(1~1.02)
오실레이션을 느린 주기(예: 8~10초)로 무한 반복 — "바람에 산들거리는" 느낌을
정지 사진 안에서 과장 없이 표현한다. 개별 나뭇가지 애니메이션은 하지 않는다
(단일 사진이라 레이어 분리가 불가능하므로).

### 달빛 커서 추적
- `mousemove` 이벤트로 커서 좌표를 추적해 `radial-gradient` 글로우(흰색, 반투명)를
  커서 위치에 렌더링하는 오버레이 `div`를 배경 이미지 위에 겹침
- `mix-blend-mode: screen`으로 블렌딩해 사진 위에서 자연스럽게 밝아지는 느낌
- 글로우는 `motion`의 스프링(약한 딜레이)으로 커서를 뒤따라가게 해 부드러운 추적감 부여
- 모바일/터치 환경에서는 mousemove가 없으므로 글로우 없이 정적 배경만 표시 (기능 저하 없이 우아하게 생략)

### 카드 레이아웃
기존 이름 선택 카드(5명)는 그대로 유지하되, 배경이 어두운 사진이므로 카드에
`backdrop-blur` + 반투명 화이트 배경을 적용해 가독성 확보.
